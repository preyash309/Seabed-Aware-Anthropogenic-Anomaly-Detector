# Offline research selection

The 22 original research scripts selected into `ml/` remain historical implementations. Nineteen are byte-identical to their archived originals; the three dataset builders in `Dataset/` now have path configuration and a safety gate. Their historical source bytes are preserved in `research/original/`. The complete 31-script archive has a SHA-256 ledger at `research/source_manifest.json`; external result and dataset hashes are in `ASSET_MANIFEST.md`.

Supported, non-destructive offline evaluation: from the repository root run `python -B research/verify_fixtures.py` for asset, calibration and fixed-image hash preflight, then `python -B research/verify_fixtures.py --run` for the two golden inference tests. Set `SAAD_ARTIFACT_DIR` to the audited external asset root and optionally `SAAD_GOLDEN_IMAGE_DIR` to a mirror containing the three verified image basenames. Set `YOLO_AUTOINSTALL=False` and `YOLO_CONFIG_DIR` under `var/` for the numerical run. This evaluates frozen models; it does not train them.

The three dataset builders support `--dry-run` with no writes. An actual build requires `SAAD_ALLOW_DATASET_BUILD=YES`, an existing read-only source path, and a new output directory below `var/research_datasets` in this clean repository. They refuse existing outputs and never delete or overwrite prepared datasets. Their full rebuilds have **not** been executed during migration. See `research/STATUS.md` for classification, input integrity caveats and exact commands. Other `ml/` scripts retain hardcoded historical paths and are **not** supported entry points for unattended execution.
