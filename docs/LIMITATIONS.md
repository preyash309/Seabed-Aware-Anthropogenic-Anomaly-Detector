# Limitations and responsible use

SAAD is verified as a **local loopback research application** on one Windows RTX 4070 Laptop GPU machine. The API has no authentication or per-user authorization; do not bind it to a public or shared network interface. Multi-user review coordination, external deployment and production security controls have not been validated. Uploaded images, review decisions and SQLite state remain on the local machine; arrange access and backups accordingly.

## Evidence and model claims

The five frozen tensors and live calibration are externally supplied and validated by manifest hash. The repository provides no weights or datasets and no public download link. `saad-live-api-v1` is the only deployed policy. Offline Evidence Engine v3 is historical research with different priority and uncertainty logic; its results must not be presented as live API output. Evidence scores rank candidates for human review and are **not calibrated probabilities**. A human decision is stored separately from the immutable model prediction.

The fixed-image golden suite establishes same-environment repeatability and migration parity on the audited GPU, not detection accuracy or cross-hardware reproducibility. CPU model inference, another GPU, another Windows machine, non-Windows numerical parity, retraining and historical offline experiment reruns are unverified. The local fresh wheel installation passed only on the audited machine. A prior intermediate environment used copied packages after a CUDA wheel download failure; the later fresh installation superseded that installation gap. During an earlier Stage 2 test Ultralytics automatically installed `pi-heif` into the original `E:/SIH/new` environment. The final clean-repository validation did not repeat or undo that change; exact pre-incident environment parity cannot be rechecked without modifying the original environment again. `YOLO_AUTOINSTALL=False` is required in documented runs.

## Data and application limits

The prepared detector train split has 45 more labels than images; an original audit found 685 missing annotations. The SubPipeMini2 temporal-neighbor report found adjacent frames across splits. These findings limit independence and performance interpretations. The three golden images are representative regression cases, not a statistically valid dataset evaluation. External dataset and model redistribution permissions are not established; no such bytes are in Git. The 31-script archive preserves source provenance, but independent code ownership and third-party licenses require publisher review. This repository has no `LICENSE` file and makes no open-source reuse grant.

The production browser workflow was tested on loopback for upload, review persistence, history, queue and report downloads. The original Analytics placeholder and decorative header controls are not verified features. PDF response signature and browser download were checked; rendered PDF text was not independently extracted. Historical training scripts and the full guarded dataset builders were not rerun. One numerical attempt while a model-loaded API was running exhausted CUDA/host memory; isolated reruns passed. Stop the API before golden regression on the audited 8 GB device.

The original `SOURCE_INVENTORY.md` is a dated source-size snapshot; for non-archived original web/backend files, size equality alone does not prove byte identity. `ASSET_MANIFEST.md` records external file hashes, and `research/source_manifest.json` records archive source hashes. See [Evaluation](EVALUATION.md) for the measured results and [Research](RESEARCH.md) for reproducibility status.
